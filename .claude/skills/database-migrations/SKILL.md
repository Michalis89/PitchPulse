# Database Migrations

Inspect current migrations and usage. Design additive migrations with keys, constraints, indexes, timestamps and clear provenance. Never edit applied migrations; avoid destructive SQL without approval. Include tests for migration application, duplicate events, referential integrity and performance-sensitive queries. Explain rollback/forward-fix strategy.
