# Feature Implementation

Clarify scope and current lead role. Inspect relevant contracts and smallest code area. Produce a short vertical-slice plan, then implement in small steps with typed API DTOs. Add deterministic demo data, handle loading/error and source classification, and run targeted tests. Update docs/progress.md and summarize exact verification; for isolated parallel tasks, supply progress notes to the integrating lead who owns that shared file. No commit or push without approval.
