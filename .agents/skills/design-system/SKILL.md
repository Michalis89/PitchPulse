# Design System

Read docs/design-system.md. Reuse semantic design tokens, shared components and scale; don't introduce local hex values and magic spacing without justification. Ensure dark surfaces, clear live/demo status, consistent team comparison, score typography, empty/error/loading states, keyboard and mobile behavior. Capture responsive screenshots when possible and document intentional deviations.
