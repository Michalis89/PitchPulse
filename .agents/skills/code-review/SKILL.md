# Code Review

Establish base/head diff or frozen changes and reviewer role. Read relevant spec and inspect actual code paths. Do not modify code. Rank findings P0/P1/P2/P3; each finding needs file/line, observed risk, evidence/reproduction and fix. Cover tests, data truthfulness, licensing, UX and security as relevant. Clearly distinguish verified defects from speculation. Return a concise handoff.
